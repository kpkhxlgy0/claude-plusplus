# Claude++ 0.3.13

- Keep Claude++ Settings idle while you chat. Claude++ mounts its Settings navigation and starts its update checks
  when the native Settings dialog opens.
- Restore Claude's own Settings content when the dialog closes and show the Claude++ navigation when it reopens.
  Older Claude Settings layouts still work, including when Claude loads their navigation in stages.

To update on Windows, fully quit Claude, download the `claude-plusplus-0.3.13-win-x64.zip` archive and its `.sha256`
file from the [release page](https://github.com/kpkhxlgy0/claude-plusplus/releases/tag/v0.3.13), verify the checksum,
extract the ZIP, and run `install.ps1`. The ZIP includes Node.js 24.19.0.

The Windows ZIP has SHA-256 `cfdb0155d0ca3c990ab0a0afeb719998db939ebe626039577145b793fcb80c26`.
