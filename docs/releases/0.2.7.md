# Claude++ 0.2.7

Claude++ 0.2.7 fixes explicit Claude Code UUID targeting for the independent Claude Session Title Tweak on supported
Claude Desktop builds.

## Fixed

- `api.claude.sessionTitles.setTitle(...)` accepts the MCP handler context as an optional third argument. It first
  honors an exact Desktop manager key, then reads the bound caller snapshot and safely maps its CLI UUID to the
  caller's `local_*` key.
- Other explicit CLI UUID targets remain supported. Runtime enumerates known manager keys and reads each target through
  Desktop's `getSession(...)` snapshot API, requiring one exact match before updating.

The Runtime still validates, updates with `titleSource: "user"`, and reads the target back before reporting success.
Unknown or ambiguous IDs remain errors. MCP injection remains in memory and does not write Claude MCP or settings
configuration; successful title persistence continues to use Desktop's normal session storage.

## Tweak compatibility

Claude Session Title `0.1.1` requires Runtime `0.2.7`. Its two required tool arguments are unchanged. The Tweak passes
the read-only handler context to the title API so Claude's current CLI UUID is resolved through the caller binding,
while an explicit ID for another known Desktop session still targets that session.

## Install

Download `claude-plusplus-0.2.7-win-x64.zip`, extract it, and run:

```powershell
.\install.ps1
```

Then reinstall or refresh Claude Session Title `0.1.1` and restart Claude Desktop.
