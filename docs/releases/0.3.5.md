# Claude++ 0.3.5

Claude++ 0.3.5 restores the missing Claude++ section in the current Claude Desktop Settings interface.

## Fixes

- Recognize the new display-contents wrapper around Settings navigation and content, so Config, Tweaks, and
  Tweak Store appear again.
- Keep custom pages inside the content panel when Claude includes an optional top row.
- Preserve support for the previous layout, native page and selection restoration, and navigation remounting.

## Install or update

Fully quit Claude before updating. Download `claude-plusplus-0.3.5-win-x64.zip` and its `.sha256` checksum from the
[release page](https://github.com/kpkhxlgy0/claude-plusplus/releases/tag/v0.3.5), extract the ZIP, and run `install.ps1`.
Then run `bin\claudeplusplus.cmd doctor` and open the **Claude++** Start Menu shortcut.

Keep the official Claude Store package installed. Use the Claude++ shortcut or `bin\claudeplusplus.cmd launch`
to retain the registered Windows package identity.

## Verification

- All 648 automated tests passed, including the workspace builds.
- The Windows package passed checksum, CLI, Doctor, and Tweak authoring checks without system Node.js or npm.
- The installed fix passed all 12 Doctor checks, and the user confirmed that the Claude++ section is visible again
  on Claude Desktop 2.42304.0.
- Regression coverage includes the previous layout, the new wrapper, and a wrapper with an optional top row;
  navigation mounting, page switching, native content restoration, and remounting are checked.

Claude++ continues to patch only its managed copy of Claude. User settings and installed Tweaks are preserved.

## Known dependency warning

`npm audit --omit=dev` reports one high-severity vulnerable dependency: `brace-expansion@5.0.9`, used indirectly by
the installer's `@electron/asar` dependency. The affected pattern processing is used when repacking the local Claude
application; this release does not change or remediate that dependency.
