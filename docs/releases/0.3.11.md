# Claude++ 0.3.11

Successful Windows Store installation and maintenance now automatically remove unused older application mirrors
under `%LOCALAPPDATA%/claude-plusplus/store-apps`, following Codex++ 1.0.10.

- Keep the current application, directories referenced by running processes, newer versions, other architectures
  and publishers, and unrecognized directories.
- Check persisted installation state, native process information, directory boundaries, and reparse points before
  deletion. Uncertain checks retain the directory, and cleanup warnings do not undo a successful installation.
- Apply the same protection to normal installation, repair, watcher maintenance, and the existing
  `--cleanup-all-old` option. No new option is required.
- Preserve runtime files, installed Tweaks, recovery backups, and the official Store installation.

Fully quit Claude before updating. Download `claude-plusplus-0.3.11-win-x64.zip` and its `.sha256` checksum from the
[release page](https://github.com/kpkhxlgy0/claude-plusplus/releases/tag/v0.3.11), extract the ZIP, and run `install.ps1`.
Keep the official Claude Store package installed and launch through the **Claude++** Start Menu shortcut.

This release changes installer cleanup only. Session Stats and Remote Control transport are unchanged.
