# Claude++ 0.3.10

Claude++ 0.3.10 removes the legacy session-statistics RPC transport from core. Claude Desktop's local Code CLI owns
its Remote Control connection, so the removed Desktop main-process adapter is not the path used by that connection.
Session Stats 0.9.0 publishes and receives snapshots through the session's authenticated `client_metadata` channel
without modifying the CLI.

## Changes and compatibility

- Remove the core statistics provider service, control-request handler, native compile hooks, and compatibility
  adapters. Claude++ no longer exposes `api.sessionStats` in Main or Renderer.
- Keep the deprecated `session-stats` permission accepted by the manifest validator so existing Main-capable Tweak
  manifests still load. Keep the optional API declaration and exported SDK types for source compatibility.
- Existing Tweaks must guard access to the optional legacy API. Manifest compatibility does not restore the removed
  RPC service; use Session Stats 0.9.0 for the current Remote Control statistics transport.
- Install Session Stats 0.9.0 on both the running and receiving devices. Session Stats owns metadata publication,
  reception, aggregation, and caching; its 0.9.0 transport does not require Claude++ 0.3.10. This core release is cleanup,
  not a hard dependency of the Tweak update.

## Install or update

Fully quit Claude before updating. Download `claude-plusplus-0.3.10-win-x64.zip` and its `.sha256` checksum from the
[release page](https://github.com/kpkhxlgy0/claude-plusplus/releases/tag/v0.3.10), extract the ZIP, and run `install.ps1`.
Then open the **Claude++** Start Menu shortcut and update **Session Stats** to **0.9.0** in the Tweak Store on both
participating devices.

For a local Git checkout, install Node.js 24+ with npm, update the checkout with Git, and run its saved `install.ps1`.
Keep the official Claude Store package installed and use the Claude++ shortcut to retain its Windows package identity.

## Verification

- All 770 automated tests passed with zero failures or skips, including the SDK, Runtime, Installer, and Loader builds.
- Legacy Main-capable `session-stats` manifests still validate, Renderer-only declarations remain rejected, and Runtime
  tests confirm neither process supplies the removed API or registers the old native hook or statistics handler.
- The Windows archive passed checksum verification and isolated portable-CLI version, status, Doctor, and Tweak
  authoring checks without system Node.js or npm on PATH. The smoke check preserved an external Junction target.
- Packaged Runtime, SDK, Installer, Loader, and updated Tweak documentation match the final build. Root, workspace,
  and lockfile versions all report 0.3.10. The bundled Runtime contains none of the removed statistics service or
  adapters, while the SDK retains its deprecated optional declaration.
- PowerShell syntax and Git whitespace checks passed. The smoke check used disposable profiles and cleaned them up.

No real application installation, restart, or cross-machine Remote Control acceptance was performed for this release.
The automated package checks do not establish live acceptance of Session Stats 0.9.0 on a second device.

## Existing dependency warning

Packaging reported the unchanged six build-tree vulnerabilities (three moderate, three high) and four production-tree
vulnerabilities (three moderate, one high). This release does not change dependencies.
