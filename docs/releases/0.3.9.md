# Claude++ 0.3.9

Claude++ 0.3.9 adds an authenticated, session-scoped statistics channel for Session Stats 0.8.0.
The receiving device requests the selected session or subagent's numeric snapshot without guessing the running
device's configuration directory or requesting generic filesystem access.

## Changes

- Add the Main-only `session-stats` permission and `api.sessionStats.registerProvider(...)` API.
- Bind each request to its native Remote Control session and validate the organization, optional subagent,
  snapshot schema, numeric fields, size and age before returning data.
- Retain the existing authenticated Remote Control connection. The provider has bounded concurrency and timeouts;
  cancelled requests, revoked providers and stale connection generations cannot return old results.
- Adapt the native SDK bridge and CCR transport used by Claude Desktop `4.23118.0`, guarded by exact module hashes
  and known call sites. Unknown builds retain native behavior rather than applying an unverified patch.

## Install or update

Fully quit Claude before updating. Download `claude-plusplus-0.3.9-win-x64.zip` and its `.sha256` checksum from the
[release page](https://github.com/kpkhxlgy0/claude-plusplus/releases/tag/v0.3.9), extract the ZIP, and run `install.ps1`.
Then open the **Claude++** Start Menu shortcut and update **Session Stats** to **0.8.0** in the Tweak Store.

Update both the running and receiving devices. The core adapter loads at startup, so a full Claude restart is required;
Tweak hot reload alone cannot activate a newly installed core adapter.

For a local Git checkout, install Node.js 24+ with npm, update the checkout with Git, and run its saved `install.ps1`.
Keep the official Claude Store package installed and use the Claude++ shortcut to retain its Windows package identity.

## Scope and verification

The Session Stats Tweak continues to own aggregation and bounded caching. It stores snapshots in
`<CLAUDE_CONFIG_DIR>/.session-stats`, defaulting to `~/.claude/.session-stats`, and returns the same published sample
for local and remote reads. Independent terminal CLI Remote Control processes are outside this Desktop adapter.

Local installation, provider registration and fresh parent/subagent snapshots were verified. Actual cross-machine
Remote Control acceptance remains pending installation of both released versions on the other device.

- All 792 automated tests passed with zero failures or skips, and all four workspaces build successfully.
  The 22 focused service and native-adapter tests cover cancellation,
  queue bounds, organization checks, both module load orders and close/reconnect handling.
- Both actual hash-matched native modules passed in-memory transformation and syntax checks. Independent review
  found no remaining material issues after the transport-close fix.
- The Windows archive passed checksum verification and isolated portable-CLI version, status, Doctor and Tweak
  authoring checks without system Node.js or npm on PATH. The smoke check preserved an external Junction target.

## Existing dependency warning

Packaging reported the unchanged six build-tree vulnerabilities (three moderate, three high) and four production-tree
vulnerabilities (three moderate, one high). This release does not change dependencies.
