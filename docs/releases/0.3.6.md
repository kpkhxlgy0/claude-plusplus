# Claude++ 0.3.6

Claude++ 0.3.6 restores Main Tweak update notifications when current Claude Desktop hosts its interface in independent
WebContentsViews.

## Fixes

- Deliver Main Tweak IPC broadcasts to all live WebContents, including the independent views used by Claude's main
  interface and Settings. Previously, broadcasts reached only the BrowserWindow's own WebContents, so a completed
  update could leave its visible status unchanged.
- Keep the BrowserWindow fallback for Electron versions without the all-WebContents API and continue skipping
  destroyed targets.

## Install or update

Fully quit Claude before updating. Download `claude-plusplus-0.3.6-win-x64.zip` and its `.sha256` checksum from the
[release page](https://github.com/kpkhxlgy0/claude-plusplus/releases/tag/v0.3.6), extract the ZIP, and run `install.ps1`.
Then run `bin\claudeplusplus.cmd doctor` and open the **Claude++** Start Menu shortcut.

Keep the official Claude Store package installed. Use the Claude++ shortcut or `bin\claudeplusplus.cmd launch`
to retain the registered Windows package identity.

## Verification

- All 651 automated tests passed, including the SDK, Runtime, Installer, and Loader builds.
- Regression coverage exercises the real Runtime bootstrap and Main Tweak API with a BrowserWindow, an independent
  view, and a destroyed target, plus the BrowserWindow fallback. The independent-view assertion failed before the fix.
- The Windows archive passed checksum verification and isolated portable-CLI version, status, Doctor, and Tweak
  authoring checks without system Node.js or npm on PATH. The package smoke also rejected an external-target Junction
  and preserved its sentinel during cleanup.
- Live Claude installation, update, repair, launch, uninstall, and interface checks were not repeated for this release.

## Known dependency warning

This release inherits the 0.3.5 warning for `brace-expansion@5.0.9`, used indirectly by the installer's `@electron/asar`
dependency. Packaging reported three high-severity vulnerabilities for the complete build dependency tree and one
for the production-only package dependency tree. This release does not change or remediate dependencies.
