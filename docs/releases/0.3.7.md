# Claude++ 0.3.7

Claude++ 0.3.7 supports in-place source installation and verified online Windows installation while preserving the
active source and Node.js runtime across maintenance commands.

## Changes

- Running a saved checkout's `install.ps1` builds and installs that exact tree, including local edits, without copying
  its Git metadata into another directory. The saved script also works from a different working directory and honors
  the first Node.js and npm applications on PATH when multiple installations are available.
- The online installer resolves the official stable release, validates the exact ZIP and checksum asset locations,
  verifies SHA-256 before extraction, and invokes the packaged CLI with its bundled Node.js runtime.
- Installation records the active source directory and exact Node.js executable. CLI maintenance, Settings, and an
  already-enabled Watcher follow this binding. The stable Windows CLI launcher supports Chinese paths while preserving
  arguments, exit status, and the caller's code page.
- Installation and source updates protect Git checkouts, linked paths, unrecognized nonempty directories, and
  previous-source backups. `--force` cannot bypass these checks; failed managed-package maintenance restores the prior
  source.
- Watcher and automatic updates remain off by default. Normal installation does not create or enable Watcher tasks.

## Install or update

Fully quit Claude before updating. Download `claude-plusplus-0.3.7-win-x64.zip` and its `.sha256` checksum from the
[release page](https://github.com/kpkhxlgy0/claude-plusplus/releases/tag/v0.3.7), extract the ZIP, and run `install.ps1`.
Then run `bin\claudeplusplus.cmd doctor` and open the **Claude++** Start Menu shortcut.

To install the latest stable Windows release online:

```powershell
irm https://raw.githubusercontent.com/kpkhxlgy0/claude-plusplus/master/install.ps1 | iex
```

For a local Git checkout, install Node.js 24+ with npm, update the checkout with Git, and run its saved `install.ps1`.
Re-run the script after moving the checkout or replacing Node.js. Online installation always follows the release
download path, including when invoked from inside a checkout.

Keep the official Claude Store package installed. Use the Claude++ shortcut or `bin\claudeplusplus.cmd launch`
to retain the registered Windows package identity.

## Verification

- All 764 automated tests passed, with zero failures or skips, including the SDK, Runtime, Installer, and Loader builds.
- Coverage includes 80 bootstrap checks across Windows PowerShell 5.1 and PowerShell 7, source/Node binding, protected
  source replacement and rollback, disabled Watcher defaults, and Chinese-path launcher behavior.
- The Windows archive passed checksum verification and isolated portable-CLI version, status, Doctor, and Tweak
  authoring checks without system Node.js or npm on PATH. The package smoke also rejected an external-target Junction
  and preserved its sentinel during cleanup.
- PowerShell syntax and Git whitespace checks passed. The existing 0.3.6 Windows archive remained unchanged.
- Live Claude installation, update, repair, launch, uninstall, and interface checks were not repeated for this release.

## Known dependency warning

This release retains the existing `brace-expansion@5.0.9` warning inherited through the installer's `@electron/asar`
dependency. Packaging reported three high-severity vulnerabilities for the complete build dependency tree and one
for the production-only package dependency tree. This release does not change or remediate dependencies.
