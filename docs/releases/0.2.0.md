# Claude++ 0.2.0

Claude++ 0.2.0 is the first public Windows release of the generic Tweak platform for Claude Code Desktop.

## Highlights

- Generic SDK for Main, Renderer, and combined Tweaks.
- Isolated lifecycle, storage, IPC, filesystem, and Settings APIs.
- Config, Tweaks, and empty reviewed Tweak Store pages.
- Install, maintenance, recovery, update-channel, and opt-in Watcher commands.
- Self-contained Windows archive with a portable Node.js runtime.
- Managed-mirror installation that leaves the official Claude package unchanged.

## Install

Download `claude-plusplus-0.2.0-win-x64.zip`, extract it, and run:

```powershell
.\install.ps1
```

Use `bin\claudeplusplus.cmd doctor` after installation to verify the managed app, Runtime, Loader, Settings, config,
Store, optional Watcher, and integrity state.
