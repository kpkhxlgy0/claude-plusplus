# Claude++ 0.3.14

- Restore the Claude++ navigation when Claude Desktop opens Settings inside its dedicated portal.
- Ordinary chat updates continue to leave Claude++ Settings idle.

To update on Windows, fully quit Claude, download the `claude-plusplus-0.3.14-win-x64.zip` archive and its `.sha256`
file from the [release page](https://github.com/kpkhxlgy0/claude-plusplus/releases/tag/v0.3.14), verify the checksum,
extract the ZIP, and run `install.ps1`. The ZIP includes Node.js 24.19.0.

The Windows ZIP has SHA-256 `9f8b667a7553f1f444f4d9077b540705933f76f1b7df2da8f2a2ca05b9b94d3a`.
