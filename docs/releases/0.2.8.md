# Claude++ 0.2.8

Claude++ 0.2.8 fixes the private session-manager binding for Claude Desktop app version `1.32885.1`, corresponding
to Windows MSIX version `1.32885.1.0`.

## Fixed

Runtime 0.2.7 bound the `1.32885.1` title API to `index2.chunk-Doi9IfNA.js` export `n`. That export has a compatible
manager shape but owns cowork sessions, so neither the Claude Code UUID nor its known Desktop `local_*` ID could be
found there.

Runtime 0.2.8 instead hash-locks and binds the actual CCD manager:

- module: `index.chunk-DDK-8_aa.js`
- SHA-256: `88635924c6c13ea2b18af186af877d86c720438c39f1fa0fac23cbc776329b68`
- export: `claudeCodeSessionManager`

The existing caller-bound UUID resolution and explicit cross-session targeting now operate against the manager that
owns Claude Desktop Code sessions. Exact version, basename, hash, export, and runtime-shape checks still fail closed.

## Tweak compatibility

Claude Session Title `0.1.1` does not need an update. Its MCP tool still requires exactly two arguments,
`session_id` and `title`, and remains compatible through its existing Runtime `0.2.7` minimum.

This capability covers Claude Desktop sessions only. Claude++ injects the in-process MCP server without writing
Claude MCP or settings configuration; it does not add the tool to terminal-launched Claude Code.

## Install

Download `claude-plusplus-0.2.8-win-x64.zip`, extract it, and run:

```powershell
.\install.ps1
```

Keep the existing Claude Session Title `0.1.1` Tweak and restart Claude Desktop after installing the Runtime.
