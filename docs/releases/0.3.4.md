# Claude++ 0.3.4

Claude++ 0.3.4 fixes the missing native Claude update controls and aligns the injected Settings sidebar with current
Claude Desktop styling.

## Fixes

- Launch the managed Claude app with its registered Windows package identity. The Start Menu shortcut and CLI use
  the shared package launcher, allowing Claude to retain its native update controls.
- Refresh the package launcher and shortcut during installation and repair, including an already-current install.
- Match native Settings section spacing, selected-row colors, icon alignment, and truncated labels.
- Restore the native selected row when returning from Claude++ Settings, removing the active page, or clicking the
  previously selected native row. Preserve newer native selections and unrelated style changes.

## Install or update

Fully quit Claude before updating. Download `claude-plusplus-0.3.4-win-x64.zip` and its `.sha256` checksum from the
[release page](https://github.com/kpkhxlgy0/claude-plusplus/releases/tag/v0.3.4), extract the ZIP, and run `install.ps1`.
Then run `bin\claudeplusplus.cmd doctor` and open the **Claude++** Start Menu shortcut.

Keep the official Claude Store package installed. Opening the managed `claude.exe` directly bypasses the package
launcher; use the Claude++ shortcut or `bin\claudeplusplus.cmd launch`.
