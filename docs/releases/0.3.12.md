# Claude++ 0.3.12

This security update resolves six npm dependency alerts reported for Claude++ 0.3.11.

- The Windows installer uses `@electron/asar` 4.3.2 to read and repack Claude application archives. Its updated
  file matching dependencies include `glob` 14.0.6, `minimatch` 11.0.9, and `brace-expansion` 5.0.13.
- Source builds use Electron 42.11.18 as a development dependency with `undici` 7.30.2 in its download tooling.
  Claude Desktop supplies the Electron host when running Claude++.
- Both the full workspace and production dependency audits reported zero known vulnerabilities during release validation.

To update on Windows, fully quit Claude, download the `claude-plusplus-0.3.12-win-x64.zip` archive and its `.sha256`
file from the [release page](https://github.com/kpkhxlgy0/claude-plusplus/releases/tag/v0.3.12), verify the checksum,
extract the ZIP, and run `install.ps1`. The ZIP includes Node.js 24.19.0.

The Windows ZIP has SHA-256 `f363b32cb4f10ce57bec692882db678659299db5aa67abeeca6209e2ccfffd30`.
The local suite passed 806 tests with one platform skip. The packaged CLI passed its portable smoke tests, and a
repack of a copy of the Claude Desktop 6.28899.6.0 application archive preserved all 1,251 original entries' unpacked flags.
